# Microsoft 365 capability comparison

_Purpose: show where Neural Frontier intends to compete, complement, or integrate — honestly. Microsoft 365
is a mature suite with decades of investment; Neural Frontier today implements only its Phase 1
foundation. Product names below are used descriptively; Neural Frontier does not use Microsoft's code,
designs, or trademarks._

| Microsoft 365 area                    | Neural Frontier answer                                                                                                        | Strategy                                                                                                                 | Status today                                       |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- |
| Entra ID admin (users, groups, roles) | Frontier Identity: unified AD + Entra + Linux identity view, RBAC, audit                                                      | **Complement first** (manage Entra via Graph), native identity for non-Microsoft estates                                 | Tenant identities, RBAC, audit ✅ · Graph/AD ⬜ P2 |
| Entra Conditional Access / PIM        | Visibility via Graph; native JIT elevation with approvals                                                                     | Integrate + native governance                                                                                            | ⬜ P2/P5                                           |

## Where Neural Frontier will not compete

Desktop Office applications, consumer services, and full Exchange/Teams parity for large Microsoft-centric
enterprises. For those customers Neural Frontier is the cross-platform operations and governance layer that
sits beside Microsoft 365, connected through Microsoft Graph.
